# ADR-002: OpenReply como capability port

Status: decisão aprovada pelo responsável na solicitação da Phase 0.

Contexto: preparação documental da integração NEXORA + OpenReply, sem implementação funcional.

Decisão: OpenReply será usado como capability port; não será instalado como segundo aplicativo.

Consequência: Portar capacidades para a arquitetura NEXORA, sem operar uma aplicação paralela.

Fonte: instruções explícitas da Phase 0; este ADR não resulta de nova auditoria.
